## 🚀 Featured Projects

### 📮 [Nmail](https://github.com/nathanpenny520/Nmail) `🔧 in development`

An AI-powered local-first email client: you read, write, and make the calls — AI handles classification, filters noise, pre-writes drafts, and reports daily.

- 🔒 **Local-first** — mail data stays on your machine; pure IMAP/SMTP, plugs into Ollama / LM Studio for 100% offline inference
- 🤖 **AI capabilities** — auto-classification · noise filtering · smart drafts · daily digests (FastAPI + React/TypeScript)
- 📦 **Full distribution chain** — single-file executable, [PyPI](https://pypi.org/project/nmail-app/) (`uvx --from nmail-app nmail`), [Homebrew](https://github.com/nathanpenny520/homebrew-nmail), winget (under review), CI-driven releases
- 🌍 Official [website](https://github.com/nathanpenny520/nmail-site) (Astro + Cloudflare Workers)

### 🤖 [LocalAIAssistant](https://github.com/nathanpenny520/LocalAIAssistant) `⭐ most starred`

A Qt 6 / C++17 cross-platform AI assistant desktop app with GUI + CLI dual modes, running on macOS / Windows / Linux.

- 🗣️ **AI companion module** — 14 real-time emotions, mood system, persistent long-term memory, ASR + TTS voice interaction
- 📚 **Offline knowledge base** — ONNX Runtime embeddings + HNSW vector search, fully local with no cloud dependency
- 🛠️ **Agent task engine** — iterative self-correcting loops, 3-tier security architecture, 30+ command-injection detections, undoable file operations
